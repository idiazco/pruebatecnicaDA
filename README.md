# pruebatecnicaDA

En este repositorio se presenta todo lo necesario para la práctica. Cuenta con los csv originales, así como los procesados (invoice_supplier_processed, invoices_proceees, product_processed). Todo el código del preprocesado se encuentra en un notebook de Jupyter que se llama "pruebaETL".
Estos datos preprocesados son los que se han usado para el Dashboard de PowerBi, que tiene el nombre de practicaPowerBi. En este dashboard se ha intentando representar la imporación de los proveedores por importe facturado así como productos producidos, y también evaluar su calidad analizando los pedidos que han entregado a tiempo.

Finalmente, en el notebook titulado "practicaSQL" se encuentra el bonus track con las preguntas relacionadas con SQL.
